# kibit.go

Фронт навигатора. React, TypeScript и Vite.

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run build
npm run lint
npm run preview
```

## Ветки

Экран регистрации и входа для MVP лежит в ветке `SVGVDKAuthPage`. Учётные записи хранятся в `localStorage` браузера: это заглушка до появления бэкенда, не настоящая аутентификация.
